# Timer V1.0.0

把时间看清楚，只记录你主动选择的应用。

Timer 是一款面向 Windows 用户的应用使用时长统计工具。它不会自动统计电脑中的所有软件，只有在你主动选择应用后才会开始记录；应用关闭后再次打开，Timer 会自动继续累计时间。

## 主要功能

- 只统计用户主动添加的应用，未选择的软件不会进入记录
- 实时显示今日使用时长、前台时长、后台时长和累计总时长
- 支持工作、游戏、日常、学习等应用类别，并可自定义类别名称与颜色
- 主页饼图展示当天各类应用的使用占比
- 历史数据支持按日期范围、全部应用或单个应用查询
- 提供使用趋势、类别占比、应用排行和单应用详细统计
- 支持按时、按日、按月、按年查看柱状图或折线图
- 支持应用置顶、暂停、继续和移除
- 提供浅色、深色及多套彩色主题，并支持自定义区域颜色
- 支持开机启动、关闭后托盘计时、托盘提示和启动后隐藏
- 支持 CSV 数据导出

## 系统要求

- Windows 10 或 Windows 11
- 64 位系统
- 无需另外安装 .NET 运行环境

## 安装与启动

1. 将压缩包完整解压到一个固定文件夹。
2. 打开解压目录中的 `Timer.exe` 启动软件。
3. 启动文件路径为：`你选择的解压目录\Timer.exe`。
4. 例如解压到 `D:\Software\Timer`，需要打开的文件就是 `D:\Software\Timer\Timer.exe`。
5. 建议为 `Timer.exe` 创建桌面快捷方式，不要直接在压缩包中运行。
6. 第一次使用时，点击主页右上角的“选择已打开窗口”，选择需要统计的应用。

Timer 为单文件便携版，不写入系统目录。更新版本时，可以直接使用新版程序替换旧版 `Timer.exe`。

## 使用说明

### 添加应用

先打开需要统计的软件，再在 Timer 中点击“选择已打开窗口”。添加一次后，Timer 会记住该应用，之后重新打开时会自动继续计时。

### 计时规则

- 应用正在运行且拥有当前活动窗口时，时间计入前台。
- 应用正在运行但不是当前活动窗口时，时间计入后台。
- 同一应用的多个窗口或进程不会重复累计。
- 应用未运行、被暂停、电脑睡眠或休眠时不会累计时间。

### 历史数据

历史数据页面可以选择开始日期、结束日期和应用范围，并查看总时长、前后台时长、趋势图、类别占比和应用排行。点击应用右侧的“详细”，可以进一步按时、日、月或年查看记录。

### 托盘计时

在设置中开启“关闭窗口后继续在托盘计时”后，关闭主窗口不会退出 Timer。需要完全退出时，请使用侧栏底部的“退出 Timer”按钮或托盘菜单。

## 数据保存

所有使用记录和设置默认保存在本机：

`%LOCALAPPDATA%\Timer\usage-data.json`

Timer 不会上传应用列表、使用时长或历史记录。需要迁移电脑或备份数据时，可以在设置中点击“打开数据文件夹”，复制其中的数据文件。

## 常见问题

### 已添加的应用没有计时

确认目标应用正在运行、没有被暂停，并检查程序是否以不同权限级别启动。必要时移除该应用后重新添加。

### 选择窗口列表中找不到应用

先确认目标应用已经显示窗口，再点击列表右上角的“刷新”。部分系统组件、无窗口进程和受保护程序不会出现在列表中。

### 关闭窗口后软件仍在运行

这是因为启用了托盘计时。可以从托盘重新打开 Timer，或点击“退出 Timer”完全退出。
